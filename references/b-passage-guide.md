# B 篇语篇选题指南（v3.0，对齐 genre-typology 选材雷达 + adaptation_spec 2026-10-03 定稿；2026-10-21 增双尺说明）

本指南供 `gaokao-b-passage-finder` 技能搜索与筛选时使用。B 篇选文必须服务"可直接改编、可直接命题"——**只找有"人"的语篇**。

> **双尺提示（v3.0）**：本指南的谱系/来源/关键词服务**第一把尺（选材雷达）**；谱系过关后还须过**第二把尺「结构预检」**（三段完整/空弧检测/引语生态/升华支撑/时间线闭合五查＋叙事策略结构盘点），细则见 `references/structure-precheck.md`。**谱系合格 ≠ 结构合格**：A1/A2 靶心素材也可能空弧、无升华、引语悬空——两把尺依次过，不得过一把就推。

## 一、B 篇语篇共性（22–26 五年 23 套真题全量分类定稿）

- **篇幅**：改编后成品 **280–320 词、4–5 段**（Fred 老师 2026-10-03 定稿；真题实测区间 292–330）。选文阶段上限放宽至 1000 词，超长原文截取核心段落再改编。
- **体裁谱系（4 谱系 9 型，选材的第一把尺子）**：
  - **谱系一·第一人称叙事（占 52%，靶心）**：A1 成长弧线（困境→触发→行动→领悟，北京卷五篇全此型）；A2 经验顿悟（场景对话开场→回忆→回到当下→认知升华；教师/家长视角最佳）；A3 议题引入（个人轶事引出公共议题，重心须压回"人"，已少见）
  - **谱系二·人物特写（17%，次选）**：B1 争议验证 / B2 好奇创造 / B3 人生见证 / B4 传承数据
  - **谱系三·项目报道（13%，次选）**：C 型项目推广（现象→创始人→运作→价值，每个环节由一位被引者话语推进）
  - **谱系四·知识传递（17%，淘汰）**：D1 书评 / D2 趣味科普 / D3 研究报道——**2024 年后绝迹于 B 篇位，选材红线**
- **引语**：全文 0–8 处。**第一人称叙事可零引语**（情感依据由叙述句承担）；**B/C 型特写每段基本挂靠一位被引者，原文须含 ≥2 处可保留直接引语**——这是硬前提。
- **语言**：B2 左右，超纲词少，句式不过度复杂，有 1–2 处可考"词义猜测"的语境词（靶词须课标外）。
- **结构**：清晰故事弧——叙事类能拆出 冲击→反应→升华；特写/项目类能拆出 Problem→Solution→Impact→Significance。**升华点必须存在**（"原先以为 X，后来明白 Y"或第三方承接的客观化升华），弱升华直接压缩 Q4 命题空间。
- **行文逻辑（v3.0 增，结构预检查的对象）**：转变有中间过程（非空弧：起点＋终点之间须有"冲突→回应"链）；引语不悬空（有谁/对谁/为何说的落点）；升华概念前文有种子（主张-依据前置）；时间跳跃有交代、时态基点可判。这些是下游 adaptation_spec G8–G13/G17/G20 的前移检查。
- **基调**：积极、温暖、启发性，符合高考价值观导向。

## 二、推荐来源网站（按谱系对号入座）

| 谱系目标 | 首选栏目 |
|----------|----------|
| A1/A2 第一人称叙事（靶心） | The Guardian "A moment that changed me" / "Experience" 系列、Reader's Digest 真实故事与个人感悟、NPR "This I Believe"、Salon/Vox 第一人称专栏（First Person） |
| B 型人物特写（次选） | BBC Stories、Smithsonian 人物、TIME/NPR 人物特写、Guardian 人物专访 |
| C 型项目报道（次选） | BBC/NPR/Guardian 社区项目与创变者报道（有创始人、有受益人、有引语） |
| ~~D 型科普/书评~~ | **不选**——转 `cd-passage-adapt`（C/D 篇位） |

> 避坑：BBC Outlook、TED 转录等"梗概/口语"素材偏读后续写，**不计入 B 篇底本**；Psychology Today 类心理科普除非有明确人物主线（患者/咨询师故事），否则按 D 谱系淘汰。

## 四、"好 B 篇语篇" vs "差 B 篇语篇"

| 好（入选） | 差（排除） |
|-----------|-----------|
| 第一人称叙事有完整认知弧（冲击→反应→升华） | 只有经历流水账、无"认识的变化" |
| 特写/项目有 ≥2 处可保留直接引语 | 第三人称且 0 引语（情感态度题无依据） |
| 280–1000 词、一段一意、可截取改编 | <250 词梗概、>1000 词硬核报道 |
| 有明确升华点（金句/认知转变/第三方背书） | 平淡收束（"she has no plans to stop"式） |
| 具体细节 ≥3 项（数字/时间/地点/动作） | very important / great success / many people 空泛表述 |
| 温暖正向、价值观安全 | 争议话题、负面情绪主导、无法中性化的敏感议题 |
| **有"人"**：真实人物主线/具体项目/亲历经历 | **D 谱系**：知识罗列、纯书评、纯实验报告、纯科普 |
| 情节弧独特 | volunteer 同质化模板（降优先，非淘汰） |
| **转变有中间过程**（冲突→回应链完整，v3.0） | 空弧：只留"起点＋终点"的跳跃式转变 |
| **引语有情境、说话人身份可写明**（v3.0） | 引语悬空（无谁/对谁/为何说落点）、通篇匿名 sources |
| **升华概念前文有种子**（v3.0） | 末段抛出全篇未铺垫的新概念收尾 |

## 五、推荐文档必填字段（写给下游改编/命题）

- **体裁谱系预判**：A1/A2/B1–B4/C + 选材雷达档位（靶心/次选）——改编 Part 0 与命题 Step 1 都以此为起点。
- **直接引语数**：实数 + 说话人（按引语单元口径：同一说话人同一情境连续引述算 1；引号内术语名/题目名/书名不计）；B/C 型不足 2 处必须在推荐时预警。
- **结构预检**（v3.0）：五查一行式结论 + 三段落点指认到段（只写"结构完整"四字＝返工）；轻度风险写"结构风险与改编预案"。
- **叙事策略结构**（v3.0）：命中的下游命题富矿清单（诊断句/首段自问句/预期+意外两层/排除替代解释/专家窗口/概念同位解释/否定预期开场/双线对照），各标位置。
- **故事弧要素**：叙事类标 冲击/反应/升华 各自落点；特写类标 Problem/Solution/Impact；升华点一句话写明。
- **可命题切入点**：
  - **主旨/标题题**：升华句在哪（须能支撑"言外之意"级正确项）
  - **细节题**：哪 2–3 处事实信息可设问（时间、因果、数字、行为）
  - **推断题**：哪处留白/暗示可推态度或下文；有无"预期+意外"转折层（意外结果题落点）
  - **词义题**：哪 1–2 个**课标外**语境词可考 guess meaning（课标词熟词生义不作靶词）
  - **情感态度题**：依据来源——直接引语／动作细节／第一人称叙述句／无（为"无"须预警：下游不出此类题）
- **改编要点**：需删的理论背景/术语；需保留的关键引语与细节；时态基点（人物健在/项目运转→当下基点；已故/事件终结→过去基点）；预估改编后段数（4 或 5）。
