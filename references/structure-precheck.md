# 结构预检细则（v1.0，2026-10-21）——第二把尺

> **环节定位**：本文件供 `gaokao-b-passage-finder` 在谱系判定（第一把尺）通过后、打分之前使用，把下游三层结构模型（`genre-typology.md` 体裁谱系层 / `adaptation_spec.md` Part 1 骨架层 + `deep-framework.md` 内容层）与叙事衔接结论（`adaptation_spec.md` G1–25）**前移到选材端做材料级预判**。
> **性质声明**：材料级预判，非逐句校验——查"素材有没有这些结构与原料"，不替代改编端的句级规范（G1–25）。三段判据（冲突→回应→升华）与 deep-framework 的"冲击→反应→升华"同源同口径。
> **三层正交**：体裁（这是篇什么文章）／骨架（逻辑链怎么搭）／内容（认知弧怎么走）互相独立、不得互推。本预检只判**内容层**三段与**结构原料**，骨架层（Type A/B/C × 人称轴）留给改编 Part 1 判断。

---

## 一、五查操作单（逐条执行，每条留痕）

### 查一：三段完整（内容层主查）

对叙事/特写素材按 deep-framework 三段拆解：

| 骨架段 | 拆什么 | 原料合格的模样 |
|---|---|---|
| **冲击**（打破平静的事件/张力） | 核心冲突是什么、在第几段 | 六型任一：问题困境 / 事与愿违 / 观念差异 / 挑战权威 / 性格迥异 / 突发事件。冲突可以不止一个，逐个清点 |
| **反应**（各方回应与变化） | 主角心路历程（内在认知线）＋回应方式（外在行为线）＋回应效果 | 七型任一：情感/情绪/态度/行为/思维变化、关系重塑、策略调整。**心路不得是空白**——只有事件流水账、无认知变化即不合格 |
| **升华**（认知落点） | "原先以为 X，后来明白 Y"在哪句 | 主角顿悟（Now I understand… / I've learned…）**或**第三方承接的客观化升华（专家/同事/受益者背书——记下姓名与身份）。**升华句必须能指认到句** |

特写/项目类对应拆 **Problem→Solution→Impact→Significance** 四环（缺 Significance 等同无升华）。

**五要素核对**（deep-framework 改编必保五项，选材时先查原料在不在）：
①核心的冲突（冲击）→ ②主角心路历程（反应）→ ③对冲突的回应方式（反应）→ ④回应的效果（反应→升华）→ ⑤主角学到了什么（升华）。**缺任一项即标记**；缺 ② 或 ⑤ 属重度（心路与升华是 B 篇内核，补不出）。

### 查二：空弧检测（叙事衔接 G9 前移）

人物状态转变（换行业 / 转方向 / 态度翻转）若只留"起点＋终点"、缺中间过程，即**空弧**。

- **判据自问**：把转变前后两句直接相连读一遍——读者答得出"主角是怎么走到这一步的"吗？答不出＝缺 冲突→对冲突的回应 情节链。
- **检查位置**：长人物特写常把转变过程写在后段，而摘要/导语只给结果——**预检必须看正文或至少两个以上段落**，不得只看导语判"有转变"。
- **修复原料**：原文别处有"尝试什么、受挫什么、契机是什么"的展开 → 轻度风险（改编时移入/织入）；全篇只有结果 → 重度（改编须凭空重构，标"原料不足"）。

### 查三：引语生态（B/C 型硬前提 + 质量核查）

第一把尺已卡数量（≥2 处），本查质量与生态：

1. **情境铺垫**：每处引语有"谁、对谁、为何说"的落点吗？（引语悬空＝改编须补情境或删）
2. **说话人身份**：姓名＋职务可写明？（下游 `according to [姓名]` 归因题、"负责人观点"题的落点；通篇匿名 a source says 类素材减分）
3. **说话人意图可读**：转述的忠告/警告/打趣，读者能从上下文读出"此人为何在此处说这句话"吗？（导师式告诫？反讽铺垫？）
4. **分布生态**：C 型项目报道的理想生态是"每个环节（起源/运作/价值）各由一位被引者推进"——引语集中堆在同一段＝部分环节无人推进，标分布缺陷。
5. **计数口径**（防虚报）：按**引语单元**计——一对引号 = 1 单元；同一说话人同一情境的连续引述（即使被 she says 打断）算 1 单元；嵌套不另计。**引号内术语名 / 概念名（"Division of Responsibility"）/ 作文题目（"Why is writing important?"）/ 书名 / 标语一律不计**。第一人称叙事可零引语（情感依据由叙述句承担，2025 I 卷全篇 0 处即合规）。

### 查四：升华支撑（叙事衔接 G10 / G20 前移）

- **种子检查**：末段升华引入的每个核心概念，前文有呼应/铺垫吗？（反例：升华句里的 natural balance 在全篇无一处出现——"概念凭空降落"）
- **主张-依据检查**：末段每个"为什么"（为何值得 / 为何有意义）能否在前文找到回答？
- **修复原料**：种子存在于原文前部只是没进摘要 → 轻度；全篇确无 → 查有无替代收束句（更强的金句 / 第三方背书），仍无 → 重度（升华是 Q4 唯一依据，无原料即换篇）。
- **顺带盘点升华力度**："she has no plans to stop"式平淡收束＝弱升华——原文有更强收束句则标"改编时替换"；连强收束候选都没有则降档。

### 查五：时间线闭合（叙事衔接 G8 / G12 / G13 + 时态总则前移）

1. **时间跳跃**：跨时间段（童年→大学→从业）处，素材原文有过渡交代吗？（选材端只记录"跳跃幅度"，供下游预判补过渡的成本）
2. **隐含前提**：段首句提到的项目/学位/年份，前文有来源交代吗？（By chance, her Honours project was on… 预设"她已重返大学"——前提悬空即衔接断点）
3. **基调反转**：相邻段落叙事基调反转（发现之喜→代价之苦）处有转换预告吗？
4. **时态基点可判**：人物健在/项目仍在运作 → 当下基点（现在时主干＋回溯段过去时）；人物已故/事件终结 → 过去基点。**素材信息不足以判断生死/存续 → 标"基点待核"**（改编前须查证）。
5. **生平跨度**：素材覆盖人物一生 → 评估**截取窗口**：只取一个完整转变弧（一次成长/一个项目周期），其余删；切不出完整三段 → 换篇。

## 二、叙事策略结构盘点（加分项清单）

以下结构是下游命题的富矿（出处：adaptation_spec Part 1 写作策略 × proposal_spec 真题实考考点）。命中越多分越高（结构维度 +0.5/类，封顶 5），逐项**标位置**：

| 结构 | 识别特征 | 下游命题用途 |
|---|---|---|
| **诊断句** | Then I realized that the problem was… / It made me wonder if… | 因果题落点（v2.9 诊断句+反证句考点） |
| **首段自问句** | 首段末句把问题显式抛出 | 首段态度推断题天然落点 |
| **预期＋意外两层结果** | …But I quickly learned that it also…（转折前后各一事实层） | 意外结果题（干扰项取预期层——v2.9.12 正确项抽象化规范配套） |
| **排除替代解释** | 开场先证明"问题不在能力上"（先摆学生很会写，再写失败） | 结构性堵死干扰项（归因唯一化） |
| **专家窗口** | 连续 2–3 段由外部权威主导、"我"退场（立场→方案→原理） | 归因题 + 概念释义题双落点 |
| **概念同位解释** | 抽象名词 + 同位语从句（a well-known concept called "X," where…） | 概念释义题（术语入题干式） |
| **否定预期开场** | 先否定常识印象再展开（People get in their minds an idea of…, but…） | 首段推断题 + 主旨铺垫 |
| **双线对照** | A 的现在 ↔ B（或"我"）的过去，末段对照升华 | 比较题 / 共同点题 |
| **逻辑信号词密集** | however / but / unlike / despite 出现处 | 转折推断题（命题富矿） |
| **评价性形容词收束** | 结论句位置的评价词（The results were staggering.） | 词义题靶点候选（课标外＋语境夹逼，选材端标注候选即可，准入由改编端判） |

## 三、处置规则（与 SKILL.md 主文件同步）

- **五查全过** → 直推。
- **单条轻度风险**（素材内有修复原料：中间过程在原文别处 / 种子可从前文找回 / 引语情境可补）→ 可推荐，但推荐文档必须写"**结构风险与改编预案**"，指明修复原料在原文何处。
- **≥2 条不合格，或单条重度**（无升华 / 空弧无原料 / 引语悬空无情境可补 / 时间线切不出完整三段）→ **换篇，不得带伤推荐**。
- **记入打分**：结构完整与叙事衔接维度（权重 20%）按命中情况扣分/加分，重度不合格直接低于门槛。

## 四、预检结论的写法（防空话规范）

推荐文档"结构预检"字段须写成**一行式结论 + 三段落点指认**：

```
结构预检：三段✓（冲击P1儿子不会用词典/反应P2教学与回忆/升华P4好奇心才重要）·空弧✓ ·引语生态✓（6处，说话人=作者与儿子对话）·升华支撑✓（"curiosity"于P2已现）·时间线✓（基点=当下）
```

- 只写"结构完整"四字＝返工——三段落点须具体到"哪段＋一句概括"。
- 引语写实数＋说话人构成；有术语名混入引号的不计数并注明。
- 时态基点写明依据（人物健在/项目运转 or 事件已终结）；查不到依据写"基点待核"。

## 五、与下游的交接口径

- **体裁层**：本 skill 预判（A1/A2/B1–B4/C，第一把尺产物）。
- **内容层**：本 skill 预判三段落点（查一产物）——下游改编 Design Strategy 的 `Shock / Response / Elevation` 三字段以此为起点核对。
- **骨架层（Type A/B/C × 人称轴）**：**本 skill 不预判**，留给改编 Part 1 判断（三层正交：同为 A2，2025 I 卷是 Type C、2026 浙江首考是 Type B——见"第一人称＋顿悟"就判 Type C 是下游明令禁止的互推错误）。
- **句级规范**（分号禁令/状语前置逗号/句式多样性下限/生词三档等 G1–25）：全部留给改编端执行，选材端不查也不预写。
- **叙事策略结构盘点**的结果写入推荐文档"叙事策略结构"字段，供命题端 Step 2 蓝图起草时对号入座。
